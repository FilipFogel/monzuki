ELEMENTAL DUEL – LANDSCAPE

Webbtest: Packa upp och öppna index.html i Chrome på dator. För Android Chrome rekommenderas att publicera hela webb-mappen på en statisk host så att bilderna laddas korrekt.

Android: Öppna android-app i Android Studio, låt Gradle synka och välj Build > Build APK(s). Appen låser liggande läge och kör helt offline med lokala bilder. APK är inte byggd i denna miljö.

Kortgrafiken är beskurna illustrationer från tidigare översiktsbild; de är inte separata högupplösta original.
